# Guía Quasar para FiveM

Web comunitaria no oficial para consultar comandos por script, público y función.

## Utilización

- **Web:** https://puppetpaper.github.io/guia-quasar/
- Busca por comando o nombre de script, o utiliza las vistas Administración, Trabajos, Jugadores y Consola.
- Los filtros de roles son informativos: **no restringen el acceso a la web ni conceden permisos en FiveM**.
- Puedes compartir el enlace de una vista filtrada o descargar el HTML para consultarlo sin conexión.

## Contenido y límites

La entrega contiene 577 fichas de comandos basadas en las 587 páginas públicas de las 97 secciones de Quasar Store, capturadas el 24 de octubre de 2026. Las explicaciones de comandos están en español; parte de las explicaciones del apéndice de desarrollo se conserva en el inglés original dentro de los detalles.

La guía no sustituye la configuración de cada servidor. Algunos nombres y permisos son configurables; «No especificado» significa que la documentación no los aclara, no que cualquiera pueda ejecutar el comando. No se han ejecutado estos recursos en un servidor FiveM para comprobarlos.

Fuente: https://www.quasar-store.com/docs. Los nombres, productos y textos originales citados pertenecen a sus respectivos titulares. Este proyecto no está afiliado ni respaldado por Quasar Store. Las fichas incluyen enlaces a la documentación de origen para contrastar cada entrada.

## Despliegue

Sitio estático en GitHub Pages, rama `main`, carpeta raíz. `index.html` incluye CSS, JavaScript y datos; no requiere compilación, servidor, claves ni dependencias. `.nojekyll` evita el procesamiento de Jekyll.

No incluye las capturas completas de documentación, registros de trabajo, credenciales, configuraciones privadas ni archivos del entorno de desarrollo.

Para actualizar: reemplazar `index.html` por una versión revisada, probar búsqueda/filtros y publicar el cambio. GitHub Pages realiza el despliegue automáticamente.
